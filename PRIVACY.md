# Privacy

**Last updated: August 30, 2026**

WhatsWidget is a static, client-side web application hosted on GitHub Pages. The project does not operate its own application server, user-account system, or customer database.

## Information entered in the generator

Configuration values are processed in the browser to produce the preview and embed code. The project does not intentionally transmit those values to a WhatsWidget-owned backend because no such backend exists.

Do not enter credentials, access tokens, private customer data, or confidential messages into the generator.

## GitHub Pages

GitHub may process ordinary request and diagnostic information when serving the site. GitHub's terms and privacy documentation govern that hosting activity.

## WhatsApp

Activating a generated widget opens a WhatsApp URL containing the configured phone number and, when supplied, the prepared message. WhatsApp and Meta process that interaction under their own policies. WhatsWidget does not control those services.

## Embedded copies

A website owner who installs the generated code is responsible for that website's privacy notice, consent requirements, analytics, third-party scripts, and applicable laws. Modified snippets may behave differently from the code generated by this project.

## Analytics and third-party scripts

The maintained application does not intentionally include product analytics or advertising trackers. Any future addition of telemetry or external scripts should be documented here before deployment.

## Questions

Use the support process in [SUPPORT.md](SUPPORT.md). Do not include sensitive information in a public issue.
