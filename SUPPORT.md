# Support

## Start here

- Read the [README](README.md) for setup and development instructions.
- Read [docs/EMBEDDING.md](docs/EMBEDDING.md) for publishing and troubleshooting guidance.
- Check existing [issues](https://github.com/mralexgarrido/whatswidget/issues) before opening a new one.

## Report a bug

Use the repository's **Bug report** issue form. Include the browser, device, website platform, reproduction steps, expected result, actual result, and a minimal example when possible.

Do not post private phone numbers, customer information, credentials, or unpublished website access details.

## Request a feature

Use the **Feature request** form. Explain the user problem first, then describe the proposed behavior and alternatives considered.

## Security issues

Follow [SECURITY.md](SECURITY.md). Security vulnerabilities must not be reported in a public issue.

## Service expectations

This is an open-source project provided without a paid support commitment or guaranteed response time. Clear, reproducible reports are the fastest path to a useful answer.
